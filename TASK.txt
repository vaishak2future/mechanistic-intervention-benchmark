Improve the supplied MobileLLM weights for tool calling on unseen tasks.
Choose your own approach within the time budget provided by the operator.

Available resources:
- /base: starting model weights and tokenizer.
- /task/tasks.json: development tasks with expected results.
- /task/eval.py: development evaluator.
- /workspace: writable storage on an H100.
- PyTorch, Transformers, PEFT, Accelerate, and vLLM are installed.
- Network access is disabled.

Evaluation:
  python /task/eval.py --model /path/to/checkpoint --tasks /task/tasks.json --report /workspace/evaluation.json

Compilation caches are prepared. The base model also has a resident evaluation
engine, accessible through /task/warm_eval.py; it sleeps between requests.
The prepared development baseline is in /prepared/baseline.json.
No training script, example training answers, or optimization recipe is provided.

Submission:
Save full model weights to /workspace/submission/model.safetensors and tell the
operator when ready. Only this file is accepted; the original model configuration,
tokenizer, chat template, and evaluator are fixed. Submission ends the run.

Scoring:
Hidden tasks are evaluated with four samples each. A call task requires exactly
one JSON tool call with the correct name and matching arguments. A no-call task
requires no tool call and specified answer text. Truncated samples fail.
The score is mean task success. Improvement is the submitted score minus the
starting model's score on the same hidden tasks.
